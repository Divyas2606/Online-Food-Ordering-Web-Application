🍽️ Online Food Ordering Web Application
📖 Overview

The Online Food Ordering Web Application is a Java-based full-stack web solution designed to simulate a real-world food delivery platform. It enables users to browse restaurants, view menus, manage a shopping cart, and place orders efficiently. The application is built using industry-standard Java web technologies and follows the MVC architectural pattern to ensure scalability, maintainability, and clean code structure.

✨ Key Features

Dynamic restaurant listing with complete details

Menu display based on selected restaurant

Add, update, and remove food items from cart

Session-based cart management

Order placement workflow

Relational database integration with MySQL

🛠️ Tech Stack

Backend: Java, Servlets, JDBC

Frontend: HTML5, CSS3, JSP

Database: MySQL

Web Server: Apache Tomcat

Architecture: MVC (Model–View–Controller)
